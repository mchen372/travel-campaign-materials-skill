# Prompt Templates

本文件沉淀旅游活动物料生成 skill 的可执行提示词模板。模板中的 `{变量}` 由 agent 根据用户需求、风格库和流程状态填入。

## 1. 需求解析模板

```text
你是旅游活动设计策略助手。请解析用户输入，并输出结构化需求。

用户输入：
{user_brief}

请输出：
1. 活动主题
2. 目标人群
3. 时间节点
4. 目的地 / 旅行场景
5. 情绪关键词
6. 商业目标
7. 用户明确要求
8. approval_mode：ask_user 或 auto

规则：
- 如果用户没有提供某项信息，请基于旅游垂类常识合理推断。
- 如果用户明确给出要求，必须以用户输入为准。
- 如果用户说“无需询问 / 不用问我 / 你来定 / 自动决定 / 直接做 / 直接输出”，approval_mode = auto。
- 不要开始生成视觉，只做需求解析。
```

## 2. 风格选择模板

```text
你是旅游活动视觉风格策划助手。请基于需求解析结果，从风格库中选择最适合的风格方向。

需求解析：
{parsed_requirements}

可选风格：
{style_list}

风格库说明：
{style_library_summary}

请输出：
1. 推荐 3-5 个风格方向，按匹配度排序。
2. 每个风格方向的适配理由。
3. 每个方向建议引用的风格库目录。
4. 每个方向必须引用的 2-4 张具体参考图文件路径。
5. 每个方向从参考图中提炼出的构图、色彩、字体、材质、光影、版式特征。
6. 每个方向用于生成主题化风格预览图的关键提示词。
7. 不推荐的风格及原因，最多 2 个。

规则：
- 只能从现有风格库选择，除非用户明确要求新增风格。
- 如果用户指定风格，只输出该风格，并说明为什么不再发散 3-5 个风格。
- 推荐理由必须结合活动主题、人群、节点、情绪和商业目标。
- 只做风格拍板，不要生成 5 个视觉方向。
- 不要生成视觉探索图、母版图或最终设计。
- 风格库原图只能作为参考依据，不得直接作为候选风格展示图。
- 每个候选风格都需要随后生成 1 张当前主题的风格预览图，帮助用户拍板。
- 必须选择具体参考图路径，不能只输出风格名称或风格目录。
- 后续生成提示词必须绑定这些参考图的视觉特征。
```

## 2.1 风格预览图生成模板

```text
请为候选风格生成一张当前活动主题的风格预览图。

生成方式：
- 必须使用 ChatGPT Image 2 / image2.0 生成真实位图。
- 输出 PNG 或 JPG。
- 禁止输出 SVG、HTML、CSS、canvas、Mermaid、PDF 或 JS 绘图脚本。
- 禁止直接复制或展示风格库原图。
- 生成后必须重命名为规范文件名，例如 `{campaign_slug}_style-preview_{style_option_id}_{style_slug}_16x9_v01.png`。

活动主题：
{campaign_theme}

主标题：
{main_title}

目标人群：
{target_audience}

情绪关键词：
{mood_keywords}

候选风格编号：
{style_option_id}

候选风格名称：
{style_name}

风格库参考：
{style_reference_notes}

必须参考的风格库图片路径：
{style_reference_image_paths}

从参考图提炼出的视觉特征：
{style_reference_extracted_traits}

预览图要求：
- 这张图是“当前主题套用该风格后的预览”，不是通用风格样张。
- 必须体现活动主题和旅游场景。
- 必须包含真实主标题：{main_title}
- 画面可以是横版预览构图，重点帮助用户判断风格气质。
- 只表达风格大方向，不展开 5 个不同视觉方向。
- 保持标题清晰可读，避免元素遮挡。
- 必须继承从参考图抽象出的风格特征，但要为当前主题重新创作构图、主体和信息层级。

禁止：
- 不要生成 5 张视觉探索图。
- 不要生成母版或多尺寸适配图。
- 不要使用无关行业元素。
- 不要只根据候选风格名称自行发挥。
- 不要复制、描摹、改写或高度复刻任一参考图的具体构图、主体组合、版式细节或独特元素。
- 不要把参考图当作垫图、图生图来源或改图底图。
- 如果没有可用参考图，不要生成图片，应先说明缺少风格库参考。
```

## 3. 视觉发散规划模板

```text
你是旅游活动视觉创意总监。请基于已经拍板或自动选定的单一风格，生成 5 个视觉方向。

需求解析：
{parsed_requirements}

已选风格方向：
{selected_style}

已选风格参考图路径：
{selected_style_reference_image_paths}

已选风格参考图特征：
{selected_style_reference_extracted_traits}

编号规则：
- 如果已选风格是候选风格 1，5 个视觉方向编号为 1.1 到 1.5。
- 如果已选风格是候选风格 2，5 个视觉方向编号为 2.1 到 2.5。
- 如果已选风格是候选风格 3，5 个视觉方向编号为 3.1 到 3.5。
- 总数只能是 5 个视觉方向。

请输出表格：
编号 | 风格 | 视觉方向名称 | 构图 | 核心元素 | 色彩倾向 | 字体气质 | 适合原因

规则：
- 只能围绕一个已选风格生成 5 个视觉方向。
- 不要跨多个风格一次性输出 15 个视觉方向；本阶段只能输出 5 个方向。
- 5 个视觉方向必须继续绑定已选风格的具体参考图，不能只按风格名称发挥。
- 每个视觉方向都要说明沿用了哪些参考图特征。
- 每个方向必须明显不同，避免只是换颜色。
- 视觉方向要能承载后续横版母版和多尺寸适配。
- 标题必须可读，不能让装饰元素压过主题。
- 不要生成最终图，只输出视觉发散规划。
```

## 8. 微信公众号拼接模板

```text

- 微信公众号横图：1280 × 545 px
- 微信公众号方图：545 × 545 px

1825 × 545 px

拼接规则：
- 横图放左侧，坐标 x=0, y=0。

请输出：

```
