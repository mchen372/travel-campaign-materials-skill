# Prompt Templates

本文件沉淀旅游活动物料生成 skill 的可执行提示词模板。模板中的 `{变量}` 由 agent 根据用户需求、风格库和流程状态填入。

## 1. 需求解析模板

```text
你是旅游活动设计策略助手。请解析用户输入，并输出结构化需求。

用户输入：
{user_brief}

请输出：
1. 活动主题
2. 目标人群
3. 时间节点
4. 目的地 / 旅行场景
5. 情绪关键词
6. 商业目标
7. 用户明确要求
8. approval_mode：ask_user 或 auto

规则：
- 如果用户没有提供某项信息，请基于旅游垂类常识合理推断。
- 如果用户明确给出要求，必须以用户输入为准。
- 如果用户说“无需询问 / 不用问我 / 你来定 / 自动决定 / 直接做 / 直接输出”，approval_mode = auto。
- 不要开始生成视觉，只做需求解析。
```

## 2. 风格选择模板

```text
你是旅游活动视觉风格策划助手。请基于需求解析结果，从风格库中选择最适合的风格方向。

需求解析：
{parsed_requirements}

可选风格：
{style_list}

风格库说明：
{style_library_summary}

请输出：
1. 推荐 3-5 个风格方向，按匹配度排序。
2. 每个风格方向的适配理由。
3. 每个方向建议引用的风格库目录。
4. 每个方向用于生成主题化风格预览图的关键提示词。
5. 不推荐的风格及原因，最多 2 个。

规则：
- 只能从现有风格库选择，除非用户明确要求新增风格。
- 如果用户指定风格，只输出该风格，并说明为什么不再发散 3-5 个风格。
- 推荐理由必须结合活动主题、人群、节点、情绪和商业目标。
- 只做风格拍板，不要生成 5 个视觉方向。
- 不要生成视觉探索图、母版图或最终设计。
- 风格库原图只能作为参考依据，不得直接作为候选风格展示图。
- 每个候选风格都需要随后生成 1 张当前主题的风格预览图，帮助用户拍板。
```

## 2.1 风格预览图生成模板

```text
请为候选风格生成一张当前活动主题的风格预览图。

生成方式：
- 必须使用 ChatGPT Image 2 / image2.0 生成真实位图。
- 输出 PNG 或 JPG。
- 禁止输出 SVG、HTML、CSS、canvas、Mermaid、PDF 或 JS 绘图脚本。
- 禁止直接复制或展示风格库原图。

活动主题：
{campaign_theme}

主标题：
{main_title}

目标人群：
{target_audience}

情绪关键词：
{mood_keywords}

候选风格编号：
{style_option_id}

候选风格名称：
{style_name}

风格库参考：
{style_reference_notes}

预览图要求：
- 这张图是“当前主题套用该风格后的预览”，不是通用风格样张。
- 必须体现活动主题和旅游场景。
- 必须包含真实主标题：{main_title}
- 画面可以是横版预览构图，重点帮助用户判断风格气质。
- 只表达风格大方向，不展开 5 个不同视觉方向。
- 保持标题清晰可读，避免元素遮挡。

禁止：
- 不要生成 5 张视觉探索图。
- 不要生成母版或多尺寸适配图。
- 不要使用无关行业元素。
```

## 3. 视觉发散规划模板

```text
你是旅游活动视觉创意总监。请基于已经拍板或自动选定的单一风格，生成 5 个视觉方向。

需求解析：
{parsed_requirements}

已选风格方向：
{selected_style}

编号规则：
- 如果已选风格是候选风格 1，5 个视觉方向编号为 1.1 到 1.5。
- 如果已选风格是候选风格 2，5 个视觉方向编号为 2.1 到 2.5。
- 如果已选风格是候选风格 3，5 个视觉方向编号为 3.1 到 3.5。
- 总数只能是 5 个视觉方向。

请输出表格：
编号 | 风格 | 视觉方向名称 | 构图 | 核心元素 | 色彩倾向 | 字体气质 | 适合原因

规则：
- 只能围绕一个已选风格生成 5 个视觉方向。
- 不要跨多个风格一次性输出 15 个视觉方向；本阶段只能输出 5 个方向。
- 每个方向必须明显不同，避免只是换颜色。
- 视觉方向要能承载后续横版母版和多尺寸适配。
- 标题必须可读，不能让装饰元素压过主题。
- 不要生成最终图，只输出视觉发散规划。
```

## 5. 拍板总结模板

```text
你是旅游活动视觉评审助手。请对探索方案进行总结，并给出推荐。

探索方案：
{exploration_options}

需求解析：
{parsed_requirements}

请输出：
1. 首推方案编号
2. 备选方案编号
3. 不建议方案编号，最多 3 个
4. 推荐理由
5. 如果用户想融合，建议融合方式

规则：
- 推荐必须基于用户需求，不只基于画面好看。
- 说明每个推荐方案适合什么目标。
- 在 approval_mode = ask_user 时，最后询问用户选择编号。
- 在 approval_mode = auto 时，直接输出自动选择编号和理由。
```

## 7. 多尺寸适配模板

```text
请将横版母版适配为指定物料尺寸。

生成方式：
- 必须使用 ChatGPT Image 2 / image2.0 生成真实位图适配图。
- 输出 PNG 或 JPG。
- 禁止输出 SVG、HTML、CSS、canvas、Mermaid、PDF 或 JS 绘图脚本。
- 允许对已生成位图做裁切、拼接、压缩等后处理，但不得用代码重画视觉。

母版说明：
{master_visual_summary}

目标物料：
{material_name}

目标尺寸：
{material_size}

安全区 / 规范：
{safety_rules}

适配策略：
{adaptation_strategy}

要求：
- 不要简单机械裁切。
- 主标题、核心人物面部、Logo、按钮、二维码不得进入安全区。
- 小尺寸优先保留主标题、核心视觉、品牌识别。
- 可以隐藏副标题、次级利益点、装饰元素。
- 背景和低信息装饰可以延展到安全区。
- 输出时保持画面完整、文字可读、元素不遮挡。

请输出：
1. 适配图
2. 保留元素
3. 隐藏元素
4. 安全区检查结果
```

## 8. 微信公众号拼接模板

```text
请生成微信公众号最终交付图。

生成方式：
- 横图和方图必须来自 ChatGPT Image 2 / image2.0 生成的真实位图。
- 最终交付图可以通过位图拼接后处理生成。
- 禁止用 SVG、HTML、CSS、canvas 或 JS 绘图脚本重画最终视觉。

输入：
- 微信公众号横图：1280 × 545 px
- 微信公众号方图：545 × 545 px

最终交付尺寸：
1825 × 545 px

拼接规则：
- 横图放左侧，坐标 x=0, y=0。
- 方图放右侧，坐标 x=1280, y=0。
- 横图与方图高度一致，拼接后不应出现额外留白区域。

请输出：
1. 拼接后的最终交付图
2. 拼接检查结果
```
