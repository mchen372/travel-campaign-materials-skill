# 风格库说明

本文档描述旅游活动物料生成工作流中的可选风格类型。agent 在风格发散阶段应优先从这些风格中选择，并结合本地风格库参考图生成方向。

风格库目录：

```text
style-library/
  01_collage_journal_手帐拼贴风/
  02_ecommerce_big_type_电商大字报风/
  03_cinematic_live_action_电影实景风/
  04_operational_3d_运营3D风/
  05_hand_drawn_手绘风/
  06_microsoft_style_微软风/
  07_new_chinese_新中式/
```

## 风格总表

| 风格 | 适合主题 | 典型气质 | 谨慎使用场景 |
| --- | --- | --- | --- |
| 手帐拼贴风 | 毕业旅行、城市漫游、周末出游、年轻人活动 | 青春、松弛、真实、探索感 | 强促销、大品牌正式发布 |
| 电商大字报风 | 大促、优惠、门票、节点营销 | 强转化、热闹、信息明确 | 高端品牌、文艺慢节奏活动 |
| 电影实景风 | 目的地种草、路线推荐、品牌氛围片 | 沉浸、真实、高级、叙事感 | 信息密集、价格促销 |
| 运营3D风 | 平台活动、权益包装、功能入口、轻促销 | 轻快、现代、可爱、平台感 | 需要真实目的地质感的项目 |
| 手绘风 | 亲子、自然、公益、慢旅行、城市地图 | 温暖、亲和、轻松、有手作感 | 强商业转化、科技感活动 |
| 微软风 | 科技感、效率工具、平台能力、智能体活动 | 清爽、理性、数字化、现代 | 强情绪旅游种草、传统文化活动 |
| 新中式 | 古镇、山水、节气、传统节日、文化旅游 | 雅致、东方、沉稳、文化感 | 年轻潮流、强促销、大字报活动 |

## 1. 手帐拼贴风

参考目录：

```text
style-library/01_collage_journal_手帐拼贴风/
```

适合：

- 毕业旅行季
- 城市漫游
- 年轻人打卡
- 周末出游
- 小众目的地推荐

视觉特征：

- 拼贴照片、胶带、贴纸、手写标注、票根、地图、撕纸边缘。
- 构图可以相对自由，强调“旅行记录”和“真实经历”。
- 色彩通常明快、有对比，但不必过度商业化。
- 标题可以有手写感、涂鸦感或杂志标题感。

适配建议：

- 适合在风格拍板后，作为该单一风格下 5 个视觉方向之一的青春、探索、记录感方向。
- 适合在主视觉中加入目的地照片、路线标签、日期、打卡章。
- 多尺寸适配时，小尺寸应保留主标题、核心照片和 1-2 个识别贴纸即可。

避免：

- 拼贴元素过多导致标题不可读。
- 使用过多低清照片。
- 装饰元素压过核心旅游主题。

## 2. 电商大字报风

参考目录：

```text
style-library/02_ecommerce_big_type_电商大字报风/
```

适合：

- 门票优惠
- 酒店套餐
- 节点大促
- 平台补贴
- 强运营转化活动

视觉特征：

- 大标题、大数字、强对比色块、促销标签、爆炸贴、价格感元素。
- 信息层级明确，第一眼知道利益点。
- 画面节奏热闹，适合短时间吸引点击。

适配建议：

- 主标题和利益点必须成为画面第一层级。
- 可以将目的地元素作为背景或辅助视觉，不应抢走促销信息。
- 小尺寸中优先保留大标题和核心利益点，删减复杂装饰。

避免：

- 文字过多导致廉价或难读。
- 所有信息都做成大字，层级混乱。
- 对高端、静谧、文化类主题使用过强促销语气。

## 3. 电影实景风

参考目录：

```text
style-library/03_cinematic_live_action_电影实景风/
```

适合：

- 目的地种草
- 长线旅行
- 城市大片
- 自驾路线
- 品牌氛围活动

视觉特征：

- 真实场景照片或电影感画面。
- 强调光影、景深、人物姿态、空间纵深。
- 标题更克制，常与画面构图形成叙事关系。
- 色彩可偏胶片、自然、夕阳、青绿色或高对比电影调。

适配建议：

- 优先保证主体人物、地标或目的地风景完整。
- 适合生成更高级、更沉浸的风格方向。
- 多尺寸适配时应避免粗暴裁切人物面部和目的地标志。

避免：

- 用过暗、过虚、过空的背景导致活动主题不明确。
- 标题贴在复杂背景上导致可读性差。
- 促销信息太多破坏电影感。

## 4. 运营3D风

参考目录：

```text
style-library/04_operational_3d_运营3D风/
```

适合：

- 平台节点活动
- 功能入口
- 权益包
- 任务活动
- 轻量促销

视觉特征：

- 3D 角色、物件、图标、场景台、漂浮卡片。
- 颜色明快，形体圆润，画面友好。
- 更像平台运营视觉，不强调真实目的地质感。

适配建议：

- 适合用在需要统一平台感、可复用元素、轻松氛围的活动。
- 可以把交通、行李箱、地图、门票、地标做成 3D 元素。
- 小尺寸适配时保留 1 个核心 3D 主体和标题即可。

避免：

- 3D 质感粗糙、廉价。
- 角色或物件与旅游主题关系弱。
- 用过多漂浮元素造成画面散乱。

## 5. 手绘风

参考目录：

```text
style-library/05_hand_drawn_手绘风/
```

适合：

- 亲子游
- 自然旅行
- 公益活动
- 城市地图
- 慢旅行、治愈主题

视觉特征：

- 手绘线条、插画人物、自然元素、地图感符号。
- 气质温暖、亲和、轻松。
- 色彩可以柔和，也可以明亮童趣。

适配建议：

- 适合需要亲和力、故事感、低压力的旅游主题。
- 可以将目的地路线、景点和活动步骤画成插画地图。
- 多尺寸适配时要保持线条清晰，避免细节过碎。

避免：

- 过度幼稚化，不符合成人旅游活动。
- 线条太细，小尺寸不可读。
- 插画元素过多导致标题失焦。

## 6. 微软风

参考目录：

```text
style-library/06_microsoft_style_微软风/
```

适合：

- AI 旅游助手
- 智能推荐
- 平台能力展示
- 数据化行程规划
- 科技感活动

视觉特征：

- 清爽背景、柔和渐变、半透明卡片、现代几何、理性排版。
- 视觉更偏产品化和工具感。
- 信息结构清晰，适合表达智能、效率、平台能力。

适配建议：

- 适合“旅游 + AI / 智能体 / 工具 / 推荐”主题。
- 可以用卡片、路线模块、地图点位、数据标签组织画面。
- 多尺寸适配时保持留白和清晰层级，不要做成大促海报。

避免：

- 过度抽象，缺少旅游场景感。
- 只剩科技 UI，没有目的地或出游情绪。
- 与新中式、电影实景等高情绪风格强行混合。

## 7. 新中式

参考目录：

```text
style-library/07_new_chinese_新中式/
```

适合：

- 古镇旅行
- 山水目的地
- 传统节日
- 节气活动
- 文化旅游

视觉特征：

- 山水、留白、纸纹、印章、宋体/楷体气质、东方色彩。
- 强调雅致、文化感、仪式感。
- 可结合现代排版，避免过度复古。

适配建议：

- 适合文化感和目的地气质明确的活动。
- 标题可使用更稳重的字体气质，画面留白要足。
- 多尺寸适配时保留山水 / 建筑 / 印章等核心识别元素。

避免：

- 过度传统导致像节日贺卡。
- 红金色滥用导致廉价。
- 用于年轻潮流、强促销主题时气质不匹配。

## 风格选择原则

- 用户指定风格时，用户优先。
- 用户未指定时，agent 默认从风格库中选择 3-5 个最匹配方向。
- 风格选择必须结合活动主题、人群、节点、情绪和商业目标。
- 旅游主题不能只看“好看”，还要判断是否能承载真实目的地、活动信息和后续多尺寸适配。
- 风格发散阶段必须引用对应目录中的 2-4 张具体参考图，不得只根据风格名称凭空生成。
- 生成风格预览图、视觉发散图和母版前，必须记录所用参考图文件路径。
- 生成风格预览图、视觉发散图和母版前，必须实际打开并视觉审阅参考图，不能只读取文件名、目录名或本文档里的风格文字描述。
- 风格库参考图是知识型风格参考，不是垫图、改图底图、图生图来源、描摹对象或可复制模板。
- agent 应先观察参考图并把可复用的抽象特征写入提示词，例如构图逻辑、色彩范围、字体气质、材质语言、光影方式、版式节奏和信息密度。
- 每次视觉审阅都应记录逐图观察结论：构图/版式、色彩/对比、字体、材质/纹理、光影/空间、密度/节奏、可借鉴抽象特征、禁止复制的具体细节。
- 生成结果必须结合当前主题重新创作，避免和任一参考图在构图、主体组合、版式细节上高度相似。
- 当某个风格目录没有可用参考图时，不要使用该风格生成图片，应提示用户补充风格库。
- 当 agent 无法打开或视觉观察参考图时，不要使用该风格生成图片，应提示用户补充可访问参考图或修复路径。

## 风格质量增强原则

目标不是淘汰某个风格，而是让每个进入候选的风格都尽量生成更高级、更稳定、更贴合旅游主题的结果。

通用增强规则：

- 生成前先提炼参考图的高级感来源，而不是只提炼元素名。
- 提示词必须写明主标题承载方式，避免画面漂亮但文字不可用。
- 提示词必须写明旅游主题的具象承载物，例如目的地、人物、交通、路线、节日物、地图、场景空间。
- 提示词必须写明该风格的禁忌，避免模型走向廉价、泛 AI 或模板化。
- 如果首轮图质量一般，应针对问题重写提示词并重生，最多 2 次。
- 重生后仍一般时，保留最佳版本，并在复盘中说明问题和需要补充的参考图类型。

各风格增强重点：

| 风格 | 质量增强重点 | 常见失败 | 修正方向 |
| --- | --- | --- | --- |
| 手帐拼贴风 | 控制拼贴密度，保留真实照片感和手作细节 | 元素太多、标题被淹没 | 减少贴纸数量，放大主照片和标题 |
| 电商大字报风 | 强化标题/利益点层级，控制促销色块品质 | 廉价、字太多、像低端促销 | 使用更克制的色块、少量高冲击标签、明确留白 |
| 电影实景风 | 强化真实场景、电影光影、人物/地标叙事 | 画面过暗、过空、标题弱 | 指定黄金时刻光线、前中后景、标题安全留白 |
| 运营3D风 | 强化高质量 3D 材质、统一光源、旅游符号 | 泛平台插画、塑料感、元素散 | 指定单一主 3D 场景台、统一材质、减少漂浮物 |
| 手绘风 | 强化成人友好插画、清晰线条和地图叙事 | 幼稚、碎、标题弱 | 使用 editorial illustration、清晰块面、少细节 |
| 微软风 | 强化产品级信息架构和旅游 AI 场景 | 只有科技 UI，缺少旅行情绪 | 加入路线卡、地图点位、目的地照片/模块 |
| 新中式 | 强化现代东方、文化目的地和高级留白 | 红金俗气、节日贺卡感 | 使用低饱和东方色、纸纹、山水/建筑、现代排版 |

## 风格库维护规则

- 新增参考图时放入对应风格目录。
- 文件命名使用英文风格名加三位序号，例如 `collage_journal_017.png`。
- 每类风格应优先保留质量高、方向清晰、可复用的案例。
- 低质量、重复度高、主题不清晰的图片不建议入库。
- 如果新增风格类型，需要同步创建目录并更新本文档。
